移动上网解决方案总结

发表于 2024-08-09 更新于 2025-09-30 阅读次数： 本文字数： 4.6k 阅读时长 ≈ 4 分钟

TLDR：
1. 首推大厂（中兴、华为）的5G随身wifi（例如中兴u30air，300多）。不过目前都没有低价小流量套餐了，基本要29元/月以上了。
2. 其次手机+正规运营商的卡（例如广东电信星卡，29元/200G/月）（正规卡基本没有低于29的，有一些店铺赠送做到19，9的，往往都是头几个月送，后面恢复原价），最便宜的正规卡应该是广电的惠民卡（广电在部分地区（例如江苏）被限速的非常厉害，基本没法用）
3. 大厂（例如中兴、华为）的可插卡的随身wifi（例如中兴2f32 pro）+小鲸卡。设备4g的便宜，5g的贵。小鲸卡的好处是有小套餐，流量要求不高的话，小套餐更灵活。但是 2.4Ghz的wifi频段干扰严重，对稳定性有要求的，把F32 pro用线插在设备上（手机或平板）

其他的基本都是骗。（有个舒适盾的产品，知乎上有人推荐，说大学生创业，产品看起来比较朴素，客服也比较冷淡，可能是正经产品，不过不支持typec充电）

Update20260120：
又入了一个华硕adol，支持5Ghz wifi频段，闲鱼买的破解版，可以改串插小鲸卡，5G wifi频段确实稳很多，有屏幕，开机信息和信号信息也比较清晰。但是今天户外使用突然满电关机，不知道是什么原因，再观察一下。

Update20251110:

  1. 几乎可以肯定，运营商为了促销5G，对4g进行了限速（各地视资源情况还有所不同），4g卡和设备的速率远低于4g理论速率，也低于5G上线之前的4g正常速率
  2. 根据广大网友的反馈，运营商不同渠道、等级的卡，有速率区别（签约速率），低资费的卡（例如普通物联网卡），等级较低，资源不足时可能被限速
  3. 目前运营商正规大流量卡（可以插在手机上的）基本没有低于29元/月的，大量号称19元的其实都是卡商补贴（3~6月不等），补贴期到了就变29，39，甚至59。流量需求大的可以办一个，通常29元/月就有近200G流量（正规运营商签约流量卡），日常使用戳戳有余。
  4. 如果想我一样设备比较多（流量和速度要求不高），又不想手机热点消耗手机电量，可以考虑中兴f32 pro + 小鲸卡（5.9/50G/月，9.9/108G/月）（闲鱼有成品套装，设备+卡大概在60元以内），用来给电子阅读器、平板、笔记本等设备使用，是性价比比较高的方案了。

随便用用，作为主用手机的流量补充，对稳定性要求不高，可以在闲鱼搜“海尔 随身wifi 毕业”，购买个人商家折腾好的随身wifi设备+流量卡。大概60-80元，带一张流量卡，1.3元/300G/月套餐。实测在深圳白天速度还行（30-40mbps），晚上不行，移动中切换卡感明显，胜在流量极其便宜，所在地电信信号好的情况下，速率也是够的。为什么要在闲鱼买呢？因为京东和淘宝上的商家售卖的设备和卡都是有云控和限制的（下文说），闲鱼上这种是个人买回来后破解了云控和限制，理论上可以跑满卡和设备的上线，也可以换个人的手机卡使用。

随身wifi乱象

最早是前公司老板有次买了一台随身wifi给大家推荐，我用的少，一般手机热点就够了，有个兄弟出差用的多，经常抱怨流量不够，我问他为啥不买一个，他说一个月小一百的资费，公司又不报销。我才发现原来随身wifi设备不贵，每月的套餐费不算便宜。
最近在家的时间多，电话和流量都少，因此把移动的套餐降了一降。论坛上看到随身wifi的讨论，考虑到万一外出旅游，看个视频什么的，酒店的wifi速率都不好，自己备一个随身wifi也是不错的。网友们说1.3元/300G/月的套餐，随用随充，这样也没有什么负担，设备呢就几块钱10几块钱，跟白送没什么区别。
于是我就下单了一个，两个，三个。为什么买这么多？第一个没有1.3/300G的套餐，虽然也很便宜，好像6.9/300G，但是既然有1.3的，就想来一个，顺便丢一个给家人用。然后发现这两个都及其不稳定，速度时好时坏，考虑可能是设备的原因，就又买了一个更贵的。前两个大概7快多，后一个大概20多。最后发现，主要还是这种低端物联卡本身的QOS级别不高，速率和质量的级别较低。网上有一种说法，低于1元/10G的产品，商家是亏钱的，所以就要想各种办法进行限制。随身wifi上都附带了云控，除了运营上本身对低端物联网卡的各种限制外，卖设备商家肯定通过云控也对速率做了限制。据网友反馈，商家销售的随身wifi产品，在同一个链接下可能有10来个，分为单天线单通道，双天线双通道…八天线八通道等各种，实际上设备是一样的，对速率的控制，大概都是通过设备的云控做到的。酷安和闲鱼上有大量个人销售破解版的随身wifi设备和卡，我买了一个后，验证了这种说法，破解后的随身wifi设备，在白天固定地点的速率确实高不少。但是晚上和移动中切换还是较差，比手机差。这可能是设备和物联网卡本身的限制。
当然，这种便宜的随身wifi设备还有诸多限制（否者这么低的价格，严重影响运营上自己流量和卡的销售）。首先，大部分随身wifi，卡和设备是相互绑定的，这通过几个方面实现，物理上，随身wifi使用的是esim芯片，是焊在设备上的，需要一点技术才能取下来；逻辑上，随身wifi上的esim卡绑定了设备的imei号，即使把这个esim卡拆下来改造成普通的sim卡，放到别的设备或手机中也无法使用。而随身wifi设备很多没有卡槽，也无法使用其他的物联网卡，或用户自己的手机卡。
不过，设备的方案商和生产商，为了方案的通用性，这些限制一般都不是硬件上的。例如，闲鱼上很多人售卖的破解版，就是破解了随身wifi设备，让这个设备支持改串（改imei），增加sim卡槽（有的随身wifi本身带卡槽，默认是禁用的，这种直接破解禁制，启用就可以了），这样就可以装上那种有1.3元/300G套餐的物流量卡了（esim芯片也可以从设备上拆下来，改造成普通的sim卡）。这种破解一般都会去控（也就是删除商家的云控模块），去掉商家的额外限制，让设备可以发挥设备本身和卡本身的最大能力。
那么从设备中拆出的物联卡是否可以装在手机上使用呢？理论上是可以的。但是，物联网卡和设备imei的绑定关系是在运营商侧的（推断），手机不改imei（改串）肯定是用不了的。目前手机改串都需要root，有一定技术门槛，root后的手机安全性大幅下降，大体上只能用于做随身wifi了，似乎也没有太大的必要，一个破解版的随身wifi也就40~50之间吧。

高端随身wifi及附带流量卡

目前在网上卖廉价随身wifi的都是些小厂商，低资费高流量必然各种猫腻 。但是随身wifi市场也是有正规军的。华为的天际通、联通官方随身wifi、中兴正规设备和流量卡，是比较知名的正规军，价格较贵，但是确实好用。
以中兴u30 air为例，469元一台。设备上，据网友反馈，其信号好于iphone，高铁上切换速度快，一出隧道就有信号，相比之下 ，手机要好一会。流量上，中兴官方运营的流量卡，支持移动和电信双网络（可选双网或单网），29元/50G/月，或599元一年，月流量1500G。速度基本是所选运营商正规卡速度的上限了。

正规手机卡（流量）

闲鱼上200块以内就能买到不少二手5G手机（例如闲搞机公众号推荐的iQOO U3X 、中兴远航30等），专门买一台回来插正规的流量卡开热点，也是可以作为随身wifi使用的。这就最好搭配低价大流量的正规卡了。一般正常渠道办理的手机卡，流量都比较贵。例如我的中国移动卡，119的套餐才20G的流量，10G的流量包居然要30元，而网上大量售卖的正规卡，有的19元就有100多G的流量。正规三网大流量卡对比表（实时更新中） (kdocs.cn)
当然，这些卡也有局限性。这些低价大流量的卡，都是运营商获客竞争的产物，通常其原套餐的价格也不低，流量也不多，为了获客，都提供了1~2年的优惠，从而将套餐价格降低，流量大幅提升，很多到期后就没有优惠，开始变得不划算起来，因此被称为年抛卡。这种最好不要当主卡使用，就当专门的流量卡来用，套餐到期就换一张。
