之前因为眼睛和久坐的原因，搞了一套听书方案，希望减少用眼的时间，并且在散步的时候也可以阅读。最近很少用了，一是听书效果不好，原文有讲，不赘述了；二是最近散步的时候锻炼正念，不再听书了；三是阅读的时候要经常停下来做笔记，听书做不到。

然后是发现现在手机似乎都更新了TTS引擎，例如我的古董华为手机，现在就原生带了讯飞和华为自己的TTS引擎，效果已经很好了，不需要再折腾TTS-server了。

如果阅读累了，可以听听播客来获取信息，放松一下眼睛。

所以本文的方案就没什么价值了，留着记录一下曾经有这么个折腾的经历吧。

为什么听书

上次分享了我的阅读方案：分享一下我的阅读方案 | Jerome’s Blog，最近看剧《庆余年2》，就把庆余年小说又翻出来看了下，谁知一看就放不下，从早看到晚，把脑子和眼睛都看坏了。不少影视作品中，一些年迈的达官贵人眼睛看不清了，就找个人帮他念。听书也不失为一个替代的阅读方法。

以前听书需要找有声书，大部分书是没有有声版本的，现在可以用TTS（Text-To-Sound 文本转语音），有朋友可能有印象，tts声音太难听了。不过技术进步很快，最新的AI技术媲美原声了，但是目前成本还比较高，应用也较少。但有些大厂（例如微软）提供免费的在线TTS服务，效果已经很好了。本文会介绍简单的使用方案。

听书的优缺点

听书的好处
不废眼睛：声音调的合适的话，对听力的损失也比较小。
不影响动作：走路看书不好，但是走路听书影响不大，一个人散步的时候适合听书。
催眠（个人情况）：看一些精彩的书容易越来越兴奋，尤其用手机看书。但是对我个人而言，晚上听书似乎有比较好的催眠效果，即使听《庆余年》这样的爽文小说，睡意也能很快袭来。
听书的缺点
跳转不方便：纸质书跳转最方便，电子书差点，听书跳转就要打开手机进行操作了（一般听书都是手机关屏听）
知识吸收差（个人情况）：不知道别人是否这样，对我个人来说，听书的时候，对书的印象比较浅。这可能是听书时注意力没有看书那么集中。所以听适合一些不太重要的阅读材料
无法深度思考：阅读的时候可以停下来思考，可以反复阅读加深印象。但是听书的时候很难停下来，听不懂的、没听清的也一下子就过去了
不方便做笔记：这也是一个较大的缺点，严肃阅读通常会通过反复思考、标注、笔记、摘要等方法，将知识送给未来的自己。根据我的阅读流程，听完书后，还要花费额外的时间来记录和整理笔记。所以听书只适合泛读。或者边听边做笔记。

我的听书方案

硬件：随便一部安卓手机
软件：TTS-server-android、AIReader
其他可选：微信读书
GitHub - jing332/tts-server-android是本方案的核心，建议从上述Github官方仓库下载。官网的介绍是面向程序员的，我一开始看的一头雾水。这个软件其实就是可以替代安卓手机自带的TTS服务。所有的安卓手机本身就自带了TTS服务，读者如果安装了支持TTS朗读的阅读器软件，例如AIReader，都可以通过菜单打开朗读功能，这时阅读器就会调用手机的TTS服务朗读当前的文本。但是目前绝大部分手机自带的TTS朗读效果很差，很难接受。本软件调用免费的微软在线TTS服务，语音很自然。（大家可以使用edge软件的大声朗读功能先试下，这个软件跟Edge的大声朗读使用的是相同的后台服务）。本软件的使用教程网上很多，搜一下就可以了。这个方案带来一个缺点：需要保持在线。希望随着AI的进步，以后手机自带本地AI TTS，可以达到甚至超过目前在线TTS的效果。

AIReader是一个小巧的老牌阅读器，免费，支持epub在内的很多格式。我试过不少支持tts的阅读软件，例如readEra、静读天下等，要么使用后台TTS播放功能需要付费，要么使用TTS需要付费，当然这些阅读器有个优势，可以选择TTS服务。以前网上推荐最多的讯飞有声，直接就是收月费了。使用AIReader需要注意：需要在手机TTS设置中选择“tts-server-android”为默认的TTS服务，因为AIReader没有提供TTS的选项，只能使用系统默认的。

微信读书、微信公众号这些默认就提供听书/听文章的功能，使用的是腾讯的在线TTS服务，所以效果也很好，如果没有额外需求的话，可以考虑就用这个。额外的需求是指，这种商用服务“自带”绑定功能，养熟了了可能就要杀（收费），有些人（例如我）不想形成依赖；另外微信读书现在每月只能上传3本书了；其三是虽然目前对上传的书没什么限制，但是以后就不好说了，我还是倾向/习惯本地阅读。
